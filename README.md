# AI-Native Playbook

Two practical playbooks for going AI-native:

- **SDLC**: moving engineering teams from AI-assisted to AI-native software delivery, written for B2B SaaS teams with fintech guardrails.
- **Enterprise Agentic AI Platform**: the platform an organisation needs to build, run and govern agents, from the CEO to the engineer.

**Live site:** https://pmaheshgupta.github.io/ai-native-engineering-playbook/
